# Claude + HiggTable

Claude (десктопний застосунок або Claude Code) може читати ваші таски з HiggTable замість конектора Airtable. Тільки читання: через HiggTable Claude нічого не змінює в Airtable. Працює навіть із закритою HiggTable, на даних її останньої синхронізації.

## Підключення (один раз)

1. Оновіть HiggTable до **1.10.1** або новішої. На Mac програма має лежати в «Applications», а не запускатися з .dmg.
2. HiggTable → **Settings** → **Claude** → оберіть себе в **I am**.
3. Натисніть **Connect to Claude Desktop**. Статус має стати **Connected**.
4. Повністю закрийте Claude (на Mac ⌘Q, на Windows ще й з трею) і відкрийте знову.
5. У новому чаті спитайте: «які в мене відкриті таски?».

**Claude Code:** кнопка **Claude Code command** копіює команду. Вставте її в термінал і відкрийте нову сесію Claude Code.

Після цього конектор Airtable у Claude можна відключити, щоб звільнити місце для колег.

## Що можна питати

- «Які в мене відкриті таски?», «що в мене горить цього тижня?»
- «Дай бриф до LO_15945», «які лінки у PL_7002?»
- «Знайди таску про cat intro» (шукає в назвах і в брифах)
- «Покажи таски ILU у PLM зі статусом Rework»
- «Скільки відкритих тасок у кожного дизайнера у VCP?»

## Інструменти

| Інструмент | Що робить |
|---|---|
| `my_tasks` | Відкриті таски (Rework, Ready for Design, In work) того, хто вибраний в «I am», або вказаного дизайнера. Найближчий дедлайн першим. |
| `find_tasks` | Пошук за назвою, номером (LO_15945) або словами з брифу. Фільтри: таблиця (VCP, PLM, CMC, LB, OMGF), статус, дизайнер. До 50 результатів. |
| `get_task` | Одна таска повністю: бриф, Creative Link, Figma, REF, статус, дедлайн, тип, формат, години. |
| `workload` | Відкриті та High таски по дизайнерах, як вкладка Workload. Фільтри: таблиця, продукт. |

Кожна відповідь закінчується рядком «From HiggTable · VCP synced …»: так видно, наскільки свіжі дані.

## Підказки для Claude

Цей блок можна вставити в інструкції проєкту в Claude:

```
Для тасок UT Marketing використовуй інструменти higgtable, а не конектор Airtable.
- «Мої таски» → my_tasks без designer.
- Бриф або лінки однієї таски → get_task з номером (наприклад LO_15945). Якщо збігів кілька, перепитай, яку саме.
- Пошук → find_tasks; якщо в назвах нічого немає, дивись розділ «Brief mentions it».
- Дані такі, як HiggTable синхронізувала востаннє. Якщо у відповіді є попередження, що таблицю давно не оновлювали, скажи відкрити HiggTable.
- Через higgtable нічого змінити не можна: статуси, години та лінки змінюються в HiggTable.
```

## Якщо не працює

| Що бачите | Що зробити |
|---|---|
| Claude не бачить інструментів higgtable | Перевірте **Connected** у Settings → Claude, потім повністю закрийте й відкрийте Claude. |
| «No HiggTable data found» | Відкрийте HiggTable і дочекайтеся, поки таблиці завантажаться. |
| «Connected to an old location (reconnect)» | Програму перемістили. Натисніть **Reconnect** і перезапустіть Claude. |
| Windows: після оновлення HiggTable інструменти зникли | Закрийте й відкрийте Claude (HiggTable нагадає про це). |
| «Claude's config file is not valid JSON» | Конфіг Claude пошкоджений. Напишіть Олександру, нічого не видаляйте самі. |
| «my_tasks» каже, що дизайнер не вибраний | Оберіть себе в Settings → Claude → **I am**. |
